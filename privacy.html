Privacy Policy

Applies to the application Hollowfern Uploader. Last updated: 29 August 2026.

1. Who operates this application

Hollowfern Uploader is a private, single-operator tool built and run by the owner of the Hollowfern YouTube channel. It is not published to an app store, not distributed to third parties, and has no users other than its operator. Questions: livewithcars107@gmail.com.

2. What the application does

Once per day, the application uploads one finished video file, together with its title, description and tags, to the operator's own YouTube channel. It runs on the operator's own computer or server on a schedule. There is no website, no user account system, and no service offered to anyone else.

3. Google user data the application accesses

The application requests exactly one OAuth scope:

  • https://www.googleapis.com/auth/youtube.upload — permission to upload a video file to the YouTube channel of the signed-in Google account.

This scope is used for one purpose only: publishing new Hollowfern episodes to the channel that the operator owns. The application does not access, request or store:

  • Watch history, subscriptions, playlists, comments or channel analytics.
  • Existing videos on the channel; it never edits or deletes them.
  • The Google account's name, profile photo, contacts or password.
  • Gmail, Google Drive, Calendar, Photos, or any other Google service.

4. What is stored, where, and for how long

After sign-in, Google issues an OAuth refresh token. That token is stored in a local configuration file on the operator's own machine and is used solely to obtain short-lived access tokens for the daily upload. It is never transmitted anywhere except to Google's own authentication servers.

  • No Google user data is stored on any remote database or server.
  • No Google user data is transferred to any third party.
  • No Google user data is sold, rented, or used for advertising.
  • No Google user data is used to train any AI or machine learning model.
  • No human other than the operator reads any Google user data.

The token is kept only while the automation is in use and is deleted when it is no longer needed.

Limited Use disclosure. Hollowfern Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

5. Data the application does not collect

The application has no analytics, no telemetry, no cookies, no tracking pixels and no advertising. It does not collect information about anyone who watches the videos it uploads; viewer data is handled entirely by YouTube under Google's own privacy policy.

6. Withdrawing access

Access can be revoked at any time from Google Account → Third-party apps & services. Revoking access immediately invalidates the stored token and stops all uploads.

7. Children

The application is an internal publishing tool operated by an adult. It is not directed to children and does not knowingly collect information from anyone.

8. Changes to this policy

If the application's use of Google user data changes, this page will be updated and the date at the top revised before the change takes effect.
